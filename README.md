# Last Coat (Android)

The puzzle game from the claude.ai prototype, wrapped as an Android app with Capacitor 8.

## What's where

| Path | What it is |
|---|---|
| `src/game.html` | The game itself, and the master copy. The web prototype is published from this file. |
| `scripts/build-web.mjs` | Builds `www/index.html` from the game: bundles the fonts so it works offline, saves progress to native storage, and makes the Android back button close the open panel. `--release` hides the Studio's testing tools. |
| `assets/icon.svg` | App icon artwork. `npm run icons` turns it into every Android icon and splash size. |
| `android/` | The native Android project generated by Capacitor. |
| `android/keystore.properties` | Release signing settings with the upload key password. Private, never committed. |
| `marketing/` | Store listing text and graphics, and tester recruitment messages. |
| `ads.config.json` | Your AdMob app id and rewarded ad unit id (Google's test ids until you swap in your own). |
| `docs/` | The public website, served by GitHub Pages from this folder. Privacy policy: https://bobfisher2008.github.io/Games/last-coat/privacy.html |

## Commands

| Command | What it does |
|---|---|
| `npm run phone` | Build and install the debug app on a phone connected by USB (USB debugging on). |
| `npm run apk` | Build a debug APK at `android/app/build/outputs/apk/debug/app-debug.apk`. |
| `npm run bundle` | Build the signed release `.aab` for Google Play at `android/app/build/outputs/bundle/release/app-release.aab`. Testing tools are hidden in this build. |
| `npm run icons` | Regenerate the app icon and splash images from `assets/icon.svg`. |
| `npm run upload-key` | Create the Google Play upload key (only once; it refuses to overwrite). |
| `npm run build` / `npm run sync` | Rebuild `www/` / rebuild and copy it into `android/`. |
| `npm run open` | Open the Android project in Android Studio. |

The `apk`, `phone` and `bundle` commands run Gradle through `scripts/gradle.mjs`, which picks Java 21 and the Android SDK automatically.

## Upload key: back it up

Release builds are signed with `C:\Users\batmu\last-coat-keys\last-coat-upload.jks`. Its password is in `android/keystore.properties`.

**Back up both files** somewhere private, such as a password manager or an encrypted USB drive. If they're lost, Google Play support can reset the upload key, but that takes time and blocks updates until it's done. Never share them or commit them.

## Java version

Capacitor 8 builds need **Java 21**. Android Studio ships with Java 25, which this Gradle version can't run on ("Unsupported class file major version 69").

- Command line: Java 21 lives in `C:\Users\batmu\.jdks\jdk-21.0.13+9` and `scripts/gradle.mjs` uses it automatically.
- Android Studio: if the Gradle sync fails, go to Settings → Build, Execution, Deployment → Build Tools → Gradle → **Gradle JDK** and choose `jdk-21.0.13+9`.

## Ads (AdMob)

- **Debug builds** (`npm run phone`, `npm run apk`) always show Google's test ad, so it's safe to tap ads on your own phone. Never tap real ads in your own app: AdMob can suspend the account for it.
- **Release builds** (`npm run bundle`) use the ids in `ads.config.json`. Until you replace Google's test ids there, `npm run bundle` prints a reminder.
- In the EEA and UK, Google's consent form appears at first launch. Those players also get an "Ad privacy choices" button in Studio → Settings.

When your AdMob account is approved:
1. AdMob → **Apps → Add app** → Android. Copy the **App ID** (`ca-app-pub-…~…`).
2. In that app: **Ad units → Add ad unit → Rewarded**. Copy the **ad unit ID** (`ca-app-pub-…/…`).
3. Put both into `ads.config.json`.
4. AdMob → **Privacy & messaging** → create and publish a **European regulations** message for the app. Without it, no consent form appears and ads in the EEA and UK are limited.
5. `npm run bundle`, then increase `versionCode` and upload.

To see the consent form on your own phone: run `npm run phone`, find `addTestDeviceHashedId("…")` in Android Studio's Logcat, then run `$env:LC_CONSENT_TEST_DEVICE="…"; npm run phone` in PowerShell. The phone then acts as if it's in the EEA.

## Before the first Google Play upload

- [x] App icon and splash screen
- [x] Upload key and signed release bundle
- [x] Testing tools hidden in release builds
- [ ] Confirm the app id `com.lastcoat.game`. It becomes permanent after the first upload. To change it, edit `capacitor.config.json`, plus `namespace` and `applicationId` in `android/app/build.gradle`.
- [x] AdMob rewarded ads, with Google's consent form for the EEA and UK
- [ ] Put your own AdMob ids in `ads.config.json` and publish the consent message (see "Ads" below)
- [x] Privacy policy at https://bobfisher2008.github.io/Games/last-coat/privacy.html, also linked in the game (Studio → Settings). GitHub Pages serves it from `docs/` (repo Settings → Pages → Deploy from a branch → `main`, `/docs`).
- [ ] `app-ads.txt`, once the AdMob account exists. It must sit at the root of the domain, which a repo named `Games` can't serve, so it needs a second repo named `BobFisher2008.github.io` holding just that file.
- [x] Store listing graphics in `marketing/store/` (512×512 icon, 1024×500 feature graphic, six 1080×1920 screenshots). Regenerate with `npm run store-graphics` after visual changes.
- [x] Store listing text in `marketing/store-listing.md` (name, short and full description, first release notes, other Play Console fields)
- [ ] Increase `versionCode` in `android/app/build.gradle` for every upload
